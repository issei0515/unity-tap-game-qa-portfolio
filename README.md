# Unity Tap Game QA Portfolio

## 1. プロジェクト概要

自身で開発したUnity 2Dスマートフォン向けタップゲームを対象に、
テスト計画、テスト設計、テスト実行、不具合報告を行うQAポートフォリオです。

## 2. ゲーム概要

画面上に配置された数字オブジェクトをタップし、
選択した数字の合計を目標値と一致させるゲームです。

## 3. QA活動の目的

以下の能力をポートフォリオとして示すことを目的とします。

- 仕様の整理
- テスト計画の作成
- テストケースの作成
- 正常系・異常系テスト
- 不具合の報告
- テスト結果の整理
- GitHubを使用した成果物管理

## 4. テスト対象

- 目標値の生成
- 数字オブジェクトのタップ
- 現在値の計算
- 正解・不正解の判定
- タップ入力の制御
- メッセージ表示
- リセット処理
- アニメーション
- スコア表示
- 画面遷移

## 5. 使用ツール

- Unity
- GitHub
- Markdown
- ExcelまたはCSV
- Windows 11
