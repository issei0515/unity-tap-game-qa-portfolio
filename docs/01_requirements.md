# 要件一覧

## 1. 文書情報

| 項目 | 内容 |
|---|---|
| 対象システム | Unity 2Dタップゲーム |
| 文書名 | 要件一覧 |
| 作成目的 | テスト対象となる機能と期待動作を明確にする |
| 作成者 | issei |
| 作成日 | 2026年8月24日 |

## 2. 要件

| 要件ID | 機能 | 要件内容 | 優先度 |
|---|---|---|---|
| REQ-001 | 目標値生成 | ゲーム開始時に3～55の範囲で整数の目標値を生成する | 高 |
| REQ-002 | 目標値表示 | 生成した目標値を画面に表示する | 高 |
| REQ-003 | タップ入力 | 数字オブジェクトをタップしたとき、その数字を1回だけ受け付ける | 高 |
| REQ-004 | 現在値計算 | タップした数字を現在値へ正しく加算する | 高 |
| REQ-005 | 現在値表示 | 計算後の現在値を画面に表示する | 高 |
| REQ-006 | 入力制御 | Check処理中は数字オブジェクトをタップできない | 高 |
| REQ-007 | 正解判定 | 現在値と目標値が同じ場合は正解として処理する | 高 |
| REQ-008 | 不正解判定 | 現在値と目標値が異なる場合は不正解として処理する | 高 |
| REQ-009 | 正解メッセージ | 正解時にThankYouMessageを表示する | 中 |
| REQ-010 | 不正解メッセージ | 不正解時にRequestMessageを表示する | 中 |
| REQ-011 | 現在値リセット | リセット時に現在値を0へ戻す | 高 |
| REQ-012 | 目標値再生成 | リセット時に新しい目標値を生成する | 高 |
| REQ-013 | オブジェクト再配置 | リセット時に既存オブジェクトを削除して指定位置へ再配置する | 高 |
| REQ-014 | アニメーション | タップしていないときは不要なアニメーションを再生しない | 中 |
| REQ-015 | スコア記録 | 正解数と不正解数を正しく記録する | 高 |
| REQ-016 | スコア表示 | スコア画面に正解数と不正解数を表示する | 中 |
| REQ-017 | 画面遷移 | 各ボタンを押したとき、指定されたシーンへ移動する | 高 |
| REQ-018 | 二重入力防止 | 同じタップ操作が意図せず複数回加算されない | 高 |

## 3. 対象外

今回の最初のテストでは、以下を対象外とします。

- Android端末ごとの性能比較
- iPhone端末ごとの性能比較
- 長時間連続プレイ
- 通信障害
- 多言語表示
- セキュリティテスト
