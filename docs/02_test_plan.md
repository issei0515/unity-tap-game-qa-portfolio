## 2. テストの目的

Unity 2Dタップゲームの主要機能が、要件一覧に記載された内容どおりに動作することを確認します。

主に以下の品質を確認します。

- 数値が正しく計算されること
- 正解と不正解が正しく判定されること
- 操作できないタイミングで入力が受け付けられないこと
- リセット後にゲームを正常に再開できること
- メッセージやスコアが正しく表示されること
- 各ボタンから正しい画面へ移動できること

### 3.2 対象機能

以下の機能を今回のテスト対象とします。

1. ゲーム開始処理
2. 目標値の生成
3. 数字オブジェクトの表示
4. 数字オブジェクトのタップ
5. 現在値の計算
6. 正解・不正解の判定
7. タップ入力の制御
8. メッセージ表示
9. リセット処理
10. アニメーション
11. スコア記録・表示
12. 画面遷移

## 4. テスト対象外

今回のテストでは、以下を対象外とします。

- 複数機種での表示比較
- AndroidとiPhoneの動作比較
- 通信障害のテスト
- セキュリティテスト
- 長時間連続使用による負荷テスト
- バッテリー消費量の測定
- 多言語表示
- Unity内部のソースコードレビュー

対象外の項目は、基本機能の確認後に必要に応じて実施します。
