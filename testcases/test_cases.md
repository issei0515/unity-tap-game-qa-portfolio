## TC-001 ゲーム開始時の目標値生成

| 項目 | 内容 |
|---|---|
| テストケースID | TC-001 |
| テスト対象 | 目標値の生成と表示 |
| 関連要件 | REQ-001、REQ-002 |
| テスト分類 | 正常系、境界値 |
| 優先度 | 高 |
| 事前条件 | Unityプロジェクトを起動できること |
| テストデータ | なし |

### 操作手順

1. Unityでゲームのメインシーンを開く。
2. Playボタンを押してゲームを開始する。
3. 画面に表示された目標値を確認する。

- 目標値が画面に表示される。
- 目標値が3以上55以下の整数である。
- 目標値の表示が欠けていない。

| 事前条件 | メインゲーム画面が表示されていること |
| テストデータ | なし |

1. ゲームを開始する。
2. 最初に表示された目標値を記録する。
3. 数字オブジェクトをタップする。

- リセット後に目標値が表示される。
- 目標値が3以上55以下の整数である。
- エラーや表示崩れが発生しない。
- 同じ値が連続する可能性があるため、前回と必ず異なることは合格条件にしない。
